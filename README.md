# devops-netology Системы контроля версий | Чепелев Павел

## Игнорируемык файлы в terraform

#### Игнорируем все в дирректории 
.terraform/

#### Игнорируем файлы содержащие в названии
*.tfstate
*.tfstate.*

#### Игноририруем файлы логов
crash.log
crash.*.log

#### Игнорируем файлы содержащие переменные с конфеденциальными данными
*.tfvars
*.tfvars.json

#### Игнорируем файлы в которых указаны локальные переопределения
override.tf
override.tf.json
*_override.tf
*_override.tf.json

#### игнорируем временные файлы с информацией о блокировках
.terraform.tfstate.lock.info

#### Игнорируем файлы конфигурации командной строки
.terraformrc
terraform.rc
